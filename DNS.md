# What is a DNS?
**DNS** stands for Domain Name System. It provides a simple way to communicate with devices on the internet without remembering complex numbers that is IP address. Communication over the internet is through IP address and every devices connected to the internet has the IP address. So its not convinient to remember the IP address of these websites we want to visit, so instead of remembering 104.26.12.130, we can remember something like **www.zoooi.com** instead.

### TLD (Top Level Domain)

A TLD is the most righthand part of a domain name. So, for example, the example.com TLD is **.com**. There are 2 types of TLD's, gTLD (Generic Top Level) and ccTLD (Country Code Top Level Domain). The gTLD usually means the domain name's purpose, for example a .com would be for commerical purposes, .org for an organisation, .edu for education and .gov for government. And ccTLD used for geographical purposes for example, .ca for sites based in canada, .co.uk for sites based in United Kingdom etc...

### Second Level Domain

In the **example.com** the .com part is the TLD and example is the Second Level Domain.
